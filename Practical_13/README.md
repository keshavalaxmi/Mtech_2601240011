# Experiment 13 – Specification-First, Type-Driven and Test-First Development with AI

## Aim

To implement a program using specification-first, type-driven and test-first development with AI.

## Description

In this experiment, a Python program is developed by first defining its requirements and specification. Type hints and test cases are then used to develop and verify the program with AI assistance.

## Procedure

1. Define the requirements of the program.
2. Prepare the program specification.
3. Define the input and output types.
4. Write the test cases first.
5. Implement the required function.
6. Use AI for development assistance.
7. Run the test cases.
8. Check the program for errors.
9. Correct errors if required.
10. Verify the final output.

## Tools Used

* Python
* AI coding assistant
* Pytest

## Files Used

```text
project/
│
├── app.py
└── test_app.py
```

## Testing

The program is tested using test cases to check whether the output is correct.

Example:

```text
Input: 10
Expected: 10 is even
```

## Expected Result

```text
10 is even
Test passed successfully
```

## Conclusion

The program was successfully implemented using **specification-first, type-driven and test-first development with AI**.
